# Initial Attachments & Project Specifications

This directory contains the complete set of initial attachments, specifications, technical blueprints, and build guides provided for **DevPulse — Windows 11 Developer Cockpit & Git/Jira Companion**.

---

## 📁 Included Documents & Specifications

1. **`SYSTEM_SPECIFICATION_ROADMAP.md`**  
   Complete system architecture, feature breakdown, database schemas, and capability roadmap.

2. **`ARCHITECTURE.md`**  
   Technical deep-dive into the offline SQLite WAL engine, reactive state layer, Windows Mica/Acrylic effects, and performance telemetry.

3. **`API_INTEGRATIONS.md`**  
   Specification for GitHub, Jira, CI/CD webhooks, Slack alerts, and telemetry pipelines.

4. **`USER_GUIDE.md`**  
   Operational guide covering task tracking, Pomodoro focus flows, token vault management, and shortcuts.

5. **`WINDOWS_BUILD_GUIDE.md`**  
   Step-by-step instructions for native Windows 11 MSVC/NSIS compilation.

6. **`DOCKER_WINDOWS_BUILD_GUIDE.md`**  
   Docker containerized cross-compilation pipeline utilizing Debian 12 Bookworm and Node.js 24 (Latest).

7. **`TAURI_WINDOWS_11_APP_PACKAGE.md`**  
   Packaging manifest and desktop integration guide.

8. **`tauri_windows_11_manifest.json`**  
   Desktop package configuration manifest and capability permissions.
